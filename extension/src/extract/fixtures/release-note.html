Release garden-tools 1.2 — Small tools for tiny gardens

A bug fix release for garden-tools, mainly to fix the watering calendar after the latest update of the weather service.

The service now returns rain totals in millimetres, which broke the reminders for gardeners who water by hand.

Short version: in the old data the following query:

rain_total(week=46)

Returns this:

{"rain": 0.4}

But in the new data the same query returns this:

{"rain": 10.2}

According to the weather service:

That was a units fix. Per the documentation, totals are in millimetres. Hence the new behavior is correct and the old one was a bug.

The workaround looks like this:

rain_total(week=46, unit="in")
