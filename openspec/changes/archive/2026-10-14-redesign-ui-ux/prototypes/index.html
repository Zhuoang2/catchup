CatchUp UI prototypes

Five visual directions (plus C2, a variant of the chosen C) for change redesign-ui-ux (#24). All five render the same screens, states, and real sample content from shared/data.js, so they differ only in design. Use the bar at the top of each prototype to switch direction, screen, state, light/dark, and a narrow 420 px window.

Chosen for implementation (2026-10-06): C7 · Front page grid. Round 1 picked C; round 2 explored variations; C3b fixed C3's typography; C7 put it on a newspaper-site grid.
